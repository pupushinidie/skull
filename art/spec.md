## 1. 风格方向（开工拍板：烛光地下酒馆，不许换）

- **题材**：地下酒馆里的一张深色木桌，几根蜡烛照着。每个玩家面前一块皮垫板，上面叠着黄铜圆垫子。
  基准图：`~/projects/pipeline/games/skull/assets/style-tavern.png`（夜间，原图 `raw/style-tavern-night.png`，pixen seed 4242）、`style-tavern-day.png`（白天，`raw/style-tavern-day.png`）。提示词在 `assets/work/kickoff.py`。
- **气氛**：暖、安静、有点神秘，但**可爱不吓人**。骷髅是卡通的大圆眼小骷髅（像样张那样），不画血、不画骨堆、不画刀。
- **垫子（核心素材，照样张）**：
  - 背面：**亮黄铜**圆垫子，刻线边框，中间三叉**漩涡纹**（样张那堆垫子顶上的花纹），颜色比两种正面亮、偏金。
  - 玫瑰面：**铜红色边**（比背面偏橙红），中间深胡桃色底，上面一朵**浮雕红玫瑰**加两片绿叶。玫瑰要比样张亮一档（样张的玫瑰在 32px 时发闷），主色 `#c8352b`。
  - 骷髅面：同样的铜红边、深底，中间一个**奶白色卡通骷髅**，两只大黑圆眼睛、小三角鼻、一排小牙，占满内圈 70%。
  - Last Chance 碟（「公开的玫瑰碟」）：**银色 / 白镴边 + 珍珠白底 + 红玫瑰**，两面都是玫瑰。和黄铜背面一眼能分开（银 vs 金、浅底 vs 深底），也和普通玫瑰面分开（银边 vs 铜红边）。
  - 三种面（背、玫瑰、骷髅）**缩到 32px 一眼能分**：背面看整体是金色，玫瑰面看是暗底上一团红，骷髅面看是暗底上一团白。
- **硬性禁忌**：
  - 不画字：垫子、垫板、场景、封面、表情都不能有字或像字的花纹（样张的漩涡纹不能画得像字母 S / 数字 5 / 汉字）。数字和文字一律由界面用 HTML 写。
  - 封面、场景**不画人**（也不画手）。头像用动物。
  - 不像知名角色：骷髅别像《寻梦环游记》的彩绘糖骷髅、别像海盗旗；头像的蛤蟆别画成绿色青蛙（避开科米蛙）、浣熊不穿宇航服不拿枪（避开火箭浣熊）、狐狸不戴绿帽子（避开迪士尼罗宾汉）。
  - 不画像国旗的旗子。
- **光照**：夜间是蜡烛暖光，从牌桌四角往里照，四周压暗（暗角）；白天是窗户进来的暖阳光，从左上方照进来。所有小图（垫子、图标、头像、表情）统一**左上方来光**：左上一圈亮边、右下暗边，金属边上有 1–2 个高光像素点。
- **描边**：小图（垫子、图标、头像、表情、特效）一律 1px 深棕描边 `#1e0d0b`（不用纯黑），透明底，四周裁干净。场景不加描边。垫板外沿 1px `#1e0d0b`。
- **像素密度**：一张图里不混用不同密度（不要把 64px 的图缩成 32px 塞进 32px 的画布）。界面按整数倍显示：1440 / 1920 桌面 3×，1024 桌面 2×，手机对手 1×、自己的手牌 2×（见第 3 节）。不用抗锯齿、不用半透明羽化边（烟、光晕特效可以用整块的半透明色，每帧不超过 3 档透明度）。
- **场景**是唯一的例外：512×288 铺满舞台（cover），不是整数倍；上面压一层暗角渐变；垫板都画在场景上面，看不到糊的地方。

### 3.2 各尺寸下的显示倍数（推荐）

估算用的固定尺寸：顶栏 44（手机 40）、舞台内边距 12（手机 8）、提示条 36（手机 32）、右侧聊天 / 记录栏 300（1024 收进抽屉）、行间距 10（手机 6）、名牌放在垫板**右边**（宽 160；1024 宽 150；手机放在垫板**下面**，高 40）。

座位排法（6 人）：上面一排 3 个对手；中间一排左右各 1 个对手，正中间是「场上总数 + 当前叫价」；下面一排是自己（垫板 + 名牌 + 手牌 + 加注按钮）。人少时界面自己重新排、可以放大一档。

| 可视区域 | 垫板 / 垫子倍数 | 垫板显示 | 垫子显示 | 纵向合计 | 横向 | 结论 |
|---|---|---|---|---|---|---|
| 1440×790 | **3×** | 168×192 | 96×108 | 44+12+36+3×192+2×10+12 = **700** | 一个座位 168+8+160 = 336，一排 3 个 + 间距 2×16 = 1040 ≤ 1440−300−36 = 1104；自己那排：垫板 168 + 名牌 160 + 手牌 5 张 2×（5×64+4×8 = 352）+ 按钮 260 + 间距 36 = 976 | 放得下，纵向余 90 |
| 1920×960 | 3×（4× 也放得下） | 168×192（4×：224×256） | 96×108 | 3×：700；4×：44+12+36+3×256+20+12 = **892** | 4×：座位 224+8+180 = 412，一排 1236+32 ≤ 1920−300−36 = 1584 | 都放得下；4× 余 68，推荐 3× 稳妥、4× 好看，界面实测定 |
| 1024×690 | **2×** | 112×128 | 64×72 | 44+12+36+3×128+20+12 = **508** | 座位 112+8+150 = 270，一排 3 个 842 ≤ 1000（无侧栏）；自己那排：112+150+手牌 352+按钮 240+36 = 890 | 放得下，余 182。**3× 放不下**（700 > 690，横向 1040 > 1000） |
| 390×664 | 对手 **1×**，自己的手牌 **2×** | 对手 56×64；自己的垫板 1×（56×64） | 对手板上 32×36；手牌 64×72 | 40+32+对手 2 排×(64+40)+6 = 214+中间总数 44+自己（手牌 72+名牌 32）104+按钮 48+内边距 16+间距 4×6 = **518** | 对手 3 列，每格 ≤ 120：3×120+2×6+2×8 = 388 ≤ 390；手牌 4–5 张 2×：5×64+4×6 = 344 ≤ 374 | 放得下，余 146（可以给聊天条或把中间总数做大） |

要点：
1. 同一屏幕里的对手垫板、垫子用同一个倍数；**自己的手牌可以比牌桌大一档**（手机 2×，1024 可以 3× = 96，只要横向放得下）。
2. 垫子 1× 只有 32px，手机上揭牌太小：**推荐界面在中间区域放一个「揭牌聚光」**，翻哪块板，就把那张垫子按 3×（96px）在中间演一遍翻面动画，演完缩回去放到板上（桌面不需要，桌面上 3× 已经够大）。
3. 一摞 5 张在 1× 时每张只露 4px 侧边，手机上数不清：名牌上一定要有「板上 N」的数字（HTML 字，第 4.4 节的 `stack` 图标 + 数字）。

拿不准、要界面实测后定的写在交接报告里（`handoff/spec.md`「下一段要知道的」）。

### 4.8 不用单独出图的

- 揭牌前的「停顿」：界面在 `fx/flip-*` 的第 1 帧（拿起来）停 600–900ms，再一口气翻完（第 6 节）。
- pass 推到桌子中间、选中可翻的板高亮、轮到谁的光圈、加注数字步进器、场上总数大字：CSS + HTML 字。
- 「亮出我的垫子」：对每张没翻过的垫子播 `fx/flip-rose` / `fx/flip-skull`，不另出图。
- 失去的那张是什么：**只有挑战者自己**的界面里显示（用 `discs/rose` / `discs/skull`），别人只看到 `fx/lose-disc`（背面）。

## 6. 精灵图怎么播

全部横排，`background-size: N*100% 100%`，`animation: steps(N, jump-none)`（见 guluga-pixel-ui）；尊重 `prefers-reduced-motion`（翻面直接换图，特效只显示第 0 帧或不显示）。

| 文件 | 帧 | 每帧 | 播法 |
|---|---|---|---|
| `fx/flip-rose` / `flip-skull` / `flip-lc` | 8 | 第 0 帧 80ms → **第 1 帧停 700ms（悬念）** → 第 2–7 帧各 60ms | 一次，`forwards` 停在最后一帧，然后换成静态 `discs/*`。翻自己的垫子可以不停顿（自己知道是什么）；翻别人的必须停 |
| `fx/skull-hit` | 8 | 70ms | 一次，`forwards`（空帧）。和 `flip-skull` 的第 7 帧同时开始 |
| `fx/rose-pop` | 6 | 70ms | 一次，`forwards` |
| `fx/success` | 8 | 90ms | 一次，`forwards` |
| `fx/mat-win` | 8 | 80ms | 一次；第 4 帧时界面把垫板换成 `-flower` |
| `fx/lose-disc` | 8 | 90ms | 一次，`forwards` |
| `fx/snuff` | 8 | 110ms | 一次，`forwards` 停在最后一帧，然后换成 `ui/out` |
| `fx/candle` | 4 | 150ms | 循环（每根蜡烛给个随机 `animation-delay`，别一起跳） |
| `fx/petals` | 8 | 120ms | 循环 |
| `fx/sparkle` | 6 | 120ms | 循环 |
| `ui/thinking` | 4 | 250ms | 循环 |
| `emotes/*` | 4 | 160ms | 循环，气泡显示 2.4 秒（约 4 圈）后淡出。同一个人连发时新的顶掉旧的 |

## 7. 给界面的接入示例（`apps/web/src/art.ts` 归界面，照这个改）

```ts
const ROOT = `${import.meta.env.BASE_URL}art/`;

/** 座位：0–5。hex 是亮色（缝线、名牌、围巾）。 */
export const SEATS = [
  { key: "red", name: "红", hex: "#e5533f", animal: "狐狸" },
  { key: "blue", name: "蓝", hex: "#3b82f0", animal: "乌鸦" },
  { key: "green", name: "绿", hex: "#44b860", animal: "蛤蟆" },
  { key: "yellow", name: "黄", hex: "#f0c030", animal: "浣熊" },
  { key: "purple", name: "紫", hex: "#9b6ad6", animal: "黑猫" },
  { key: "cyan", name: "青", hex: "#36c2c9", animal: "獾" },
] as const;

export const DISC = { w: 32, h: 36, step: 4 } as const; // step：往上叠一张移几像素（原图）
export const FLIP = { w: 32, h: 40, frames: 8 } as const;
export const MAT = { w: 56, h: 64 } as const;
export type DiscFace = "back" | "rose" | "skull" | "lc-down" | "lc-up";
export const discArt = (face: DiscFace) => `${ROOT}discs/${face}.png`;
export const flipArt = (to: "rose" | "skull" | "lc") => `${ROOT}fx/flip-${to}.png`;
export const matArt = (seat: number, flower: boolean) => `${ROOT}mats/mat-${seat % 6}-${flower ? "flower" : "blank"}.png`;
export const avatarArt = (seat: number) => `${ROOT}avatars/avatar-${seat % 6}.png`;

export const EMOTES = ["rose", "skull", "taunt", "shrug", "think", "laugh", "sweat", "shock"] as const;
export type Emote = (typeof EMOTES)[number];
export const emoteArt = (id: Emote) => `${ROOT}emotes/${id}.png`; // 4 帧 32×32

export const sceneFor = (room: string, theme: "night" | "day") => {
  let hash = 0;
  for (const c of room) hash = (hash * 31 + c.charCodeAt(0)) >>> 0;
  return `${ROOT}scene/${theme}-${hash % 2}.png`;
};
```

垫子叠放（相对垫板左上角，scale 是整数倍，i = 0 是最底下那张，后盖的在上面、z-index 更大）：
`left = 12 * scale; top = (22 - 4 * i) * scale`。翻面时把最上面那张换成 `FLIP` 精灵图，画布比垫子高 4px，所以 `top` 再减 `4 * scale`。

图片地址固定，换图后靠服务器给 `/art/` 加 `Cache-Control: no-cache`（模板已有）。
